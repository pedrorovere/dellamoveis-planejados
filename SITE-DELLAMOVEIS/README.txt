DELLA MÓVEIS - SITE

1. Abra o arquivo index.html para visualizar o site.
2. Para testar o formulário PHP, use XAMPP:
   - coloque esta pasta em C:\xampp\htdocs\della-moveis
   - ligue o Apache
   - acesse http://localhost/della-moveis/

3. TROQUE O WHATSAPP:
   Abra php/enviar-orcamento.php e altere:
   $whatsapp = "5591999999999";

4. TROQUE AS FOTOS:
   Substitua os arquivos da pasta imagens pelos seus arquivos.
   Os SVGs incluídos são imagens de exemplo.

5. Para colocar online, contrate uma hospedagem com PHP e envie a pasta.

TECNOLOGIAS:
HTML = estrutura
CSS = visual
JavaScript = interações
PHP = processamento do formulário
